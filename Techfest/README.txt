TECHFEST 2027 - MULTI-PAGE HTML PROJECT

GETTING STARTED
Extract the entire ZIP, keeping the folders intact. Open index.html in a modern browser. No installation, internet connection or server is needed for the five pages, image, audio and PDF brochure. External college placeholder and mail links require the corresponding network/app support.

FILES
index.html       Home, SVG banner, original audio teaser, brochure download
 events.html     Five-event table and descriptions
 schedule.html   Three-day timetable with rowspan and colspan
 register.html   Accessible form with dropdown, radios, checkboxes and textarea
 contact.html    Fictional committee, mail links and college placeholder link
assets/style.css Shared responsive design
assets/script.js Local form validation and preview (no backend)
assets/festival.svg Original festival artwork
assets/teaser.wav Original synthesized audio teaser
assets/techfest-brochure.pdf Downloadable event brochure

NOTES
All event dates, venues, names and details are fictional. Fees are INR per participant. All times are IST. Phone numbers and college website are explicitly marked placeholders. The form only previews data locally; it does not transmit or persist information and collects no payment.

Bonus: downloadable PDF brochure included. A YouTube iframe is not included because this fictional event has no real YouTube teaser; the original local audio satisfies the required audio/video element without network dependency.
